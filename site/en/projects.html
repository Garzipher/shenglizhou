    • RainSoul Desktop Writing Workspace
      Electron, React, TypeScript, SQLite, Tiptap, AI-assisted development
      Problem

      Bring manuscripts, outlines, plot threads, and writing materials into one workspace, with offline writing, saving, search, export, and optional cloud AI integration.

      Data

      Store manuscripts and project data locally in SQLite, with TXT/DOCX manuscripts and project archives. Cloud API credentials are stored separately and excluded from project archive transfers.

      Approach

      Use Electron, React/TypeScript, Tiptap, and SQLite for editing, a knowledge base, version snapshots, import/export, and cloud AI configuration. I follow requirements, UI decisions, and Git iterations; AI implements the code and automated tests.

      Outcome and Impact

      A runnable Windows writing client with project documentation and learning materials. The code uses Electron safeStorage for credential encryption/decryption and SHA-256 to check archived database digests. These are software security applications and do not represent hands-on HSM experience or certification.
