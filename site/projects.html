    • RainSoul 本地写作工作台
      Electron、React、TypeScript、SQLite、Tiptap、AI 辅助开发
      项目目标

      将正文、大纲、伏笔和写作素材集中管理，支持离线写作、保存、检索及导出，并按需接入云端 AI。

      数据管理

      正文与作品资料保存在本机 SQLite，支持 TXT／DOCX 手稿和作品归档。云端 API 凭据独立存储，不随作品归档迁移。

      实现方案

      项目采用 Electron、React／TypeScript、Tiptap 和 SQLite，包含写作编辑、知识库、版本快照、导入导出及云 AI 配置。我跟进需求、UI 与 Git 迭代，由 AI 完成代码和自动化测试。

      项目成果

      已形成可运行的 Windows 写作客户端及项目说明、学习材料。代码中通过 Electron safeStorage 处理凭据加解密，通过 SHA-256 比对归档数据库摘要；这些是软件安全应用，不等同于硬件密码机实践或认证能力。

      个人参与

      跟进产品需求与功能范围、UI 方案和 Git 版本迭代。实现和测试由 AI 完成，不将其表述为本人独立编写或执行。
