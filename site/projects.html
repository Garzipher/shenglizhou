    • RainSoul 本地写作工作台
      Electron、React／TypeScript、SQLite
      项目概况

      Windows 本地写作工作台，支持离线编辑、知识管理、版本快照及导入导出。正文和作品资料保存在本机 SQLite，可按需接入云端 AI。

      个人参与

      负责功能范围梳理、UI 方案、验收要求与 Git 版本跟进，围绕离线编辑、知识管理、版本快照及导入导出推动迭代。

      问题跟进案例

      来源校验详情中的完整 SHA-256 哈希不断行，横向越出知识卡。明确问题场景与验收要求，跟进长字符串换行修复及单项回归，保留默认及 720×540 窗口下的前后对照与 Git 提交记录。

      密码应用学习

      项目采用 Electron safeStorage 处理本机 API 凭据加解密，凭据独立存储且不随作品归档迁移；使用 SHA-256 比对归档数据库摘要。这些功能作为凭据保护与完整性校验的学习案例。
